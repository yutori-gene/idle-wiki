# 装備とプロパティ

## 装備の種類

| 装備 | 効き方 |
|---|---|
| 装備必須 | 装備しているあいだ効く。装備グループ（頭部・胴体・武器など）ごとに1つだけ |
| 消費装備 | 装備して使う。使うたびに消費する（投擲の弾・爆発武器など） |
| 装備不要 | 持っているだけで効く。**所持数に比例**して効果が増える（作業部屋のインフラ・知識など） |
| 装備不可 | 効果を持たない（素材・料理など） |

装備はアイテムの管理カテゴリで付け替える。

## プロパティ

| プロパティ | 効くもの |
|---|---|
| 攻撃・防御・精度・回避・回復 | 戦闘（スタミナのアクション）だけ |
| 速度 | アクションの所要時間 |
| 成功率 | アクションの成功率 |
| 経験値 | 成功1回の経験値 |

プロパティの値は**レベル差に足し算**で効く（値10 ≒ レベル差10ぶん）。

## 効き先

各プロパティには効き先のカテゴリがある。そのカテゴリのアクション（経験値の入り先がそのカテゴリのもの）にだけ効く。

- 効き先が空のものは、アイテム自身の管理カテゴリに効く
- 「全カテゴリ」のものはすべてのカテゴリに効く（寝室の美術品など）
- 戦闘では、経験値の入り先＝武器カテゴリ（近接・投擲・爆発）に効くものだけが乗る。防具・装飾も多くは武器カテゴリ宛てに効く

装備の比較は [装備一覧](/ja/list/equipment)、カテゴリごとに効くアイテムは各カテゴリのページの「効果を与えるアイテム」。

## 武器3種

| | 近接武器 | 投擲武器 | 爆発武器 |
|---|---|---|---|
| 性格 | 継戦型（回復が高い） | 手数型（精度・速度が高い） | 一撃型（攻撃が最大） |
| 刺さる相手 | 殴る・粘る敵 | 避ける敵 | 硬い敵 |
