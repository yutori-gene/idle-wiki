# 基本のしくみ

## 要素

| 要素 | 説明 |
|---|---|
| カテゴリ | 活動の場所。ダンジョン（公園〜天空のお庭）・拠点・装備管理の3グループに分かれる。レベルを持つもの（numeric）と持たないものがある |
| アクション | カテゴリの中で実行できる行動。収集・討伐・探索・合成・分解など |
| アイテム | アクションで入手・消費・装備するもの。それぞれ「管理カテゴリ」に置かれる（入手場所ではなく、装備を付け替える場所） |
| スキル | 戦闘中に確率で発動する追加効果。敵も装備も持つ |
| イベント | タスク（条件を満たすと報酬）・隠しイベント（数量が一度に増えたときに発動）・固定のイベント（ようこそ・おかえり など） |
| グループ | カテゴリ・アクション・アイテム・イベントの分類 |

## カテゴリのレベル

- アクションが**成功**すると、経験値の入り先カテゴリ（アクションの「経験値の入り先」。無ければ置かれたカテゴリ）に経験値が入る
- レベル L から L+1 に要る経験値は 100 × levelCommonRatio^(L−1)。表は [経験値表](/ja/reference/experience)
- アクションには必要Lvがあり、入り先カテゴリのレベルがそれ以上でないと実行できない
- レベルを持たないカテゴリ（numeric=false）は経験値が入らず、レベル差の効果も受けない

## 解放（表示される条件）

- カテゴリ・アクション・アイテムは「解放条件」を満たすと現れる。カテゴリはレベルが2以上になっても解放扱いになる
- アイテムは一度でも手に入れれば解放される
- 「初期状態」は非表示（名前も出ない）・ヒント表示（名前だけ出る）・解放済み の3段階

## 売買と通貨

- 売値・買値の通貨はアイテムごとに決まっている。空欄はメイン通貨（[<span class="wiki-icon">🪙</span>コイン](/ja/item/coin)）
- 買えるアイテムは解放条件を満たすと購入できるようになる
- もう1つの通貨 [<span class="wiki-icon">🏅</span>秘宝メダル](/ja/item/treasure-medal) は、秘宝を手に入れたときにだけ増える

## 物置と作業予定

- [<span class="wiki-icon">📦</span>物置](/ja/item/capacity): 同時に持てるアイテムの**種類数**。コインで1枠ずつ買える（買うたびに高くなる）。容器を手に入れると一気に増える
- [<span class="wiki-icon">📋</span>作業予定](/ja/item/queue): 続けて実行するアクションの予約数。秘宝メダルで買う

## オフライン

- 連続・戦闘のアクションは画面を閉じているあいだも進む。戻ったときに [<span class="wiki-icon">🏠</span>おかえり](/ja/event/comeback) で結果が出る
