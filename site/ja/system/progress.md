# アクションの進み方

## 進行の種類

| 進行 | 動き |
|---|---|
| 連続 | 所要時間ごとに1回完了し、止めるまで繰り返す。オフライン中も進む |
| 単発 | 1回ずつ進む。100%になったら開封して報酬を受け取る（宝箱・合成など） |
| 即時 | 実行した瞬間に完了する |
| スタミナ（戦闘） | ターン制の戦闘。[戦闘のしくみ](/ja/system/combat) |

## 1回の完了で起きること

1. **成功判定**: 成功率で成功・失敗が決まる
2. **材料の消費**: 必要なもののうちアイテムは、成功・失敗にかかわらず**消費率で抽選して**消費する（消費率0%は「持っている・装備していること」だけが条件の道具）
3. **取得物の抽選**: 取得物は1件ずつ独立に抽選する。確率が「成功時」のものは成功したときだけ、「失敗時」のものは失敗したときだけ抽選される
4. **経験値**: 成功したときだけ入る

## レベル差

経験値の入り先カテゴリのレベルがアクションの必要Lvより高いほど、アクションは有利になる。レベル差10ごとに、効果が **propertyRatio 倍**（このワールドでは基本設定を参照）になる。

| 値 | レベル差が大きいと |
|---|---|
| 所要時間 | 短くなる（効きは半分の重み） |
| 成功率 | 上がる（0〜100%に収まるよう、成功と失敗の比に倍率がかかる） |
| 1回の経験値 | **減る**（高すぎるレベルで低いアクションを回しても伸びにくい） |

装備のプロパティ（速度・成功率・経験値）はこのレベル差に足し算で効く。各アクションのページの「計算値」に、レベル差 ±0・+10・+20・+30 の値を載せている。

## 計算値の注意

wiki の「1時間あたり」「収支」「戦闘の見込み」は、**レベル差0・装備なし・スキルなしの期待値**。実際のプレイでは装備や乱数で変わる。
