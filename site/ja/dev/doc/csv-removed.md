> idle リポジトリ `world/doc/csv-removed.md` の写し（0932eb8 時点）。編集は idle 側で行い、`npm run wiki-update` で取り込む。

**行（アイテム・アクション・カテゴリ）を消したかどうか**を後から追えるように記録する。

対象範囲は `c88b1e07`（セッション開始時点の origin/main）から `ff7937c2`（現在の HEAD）まで。
`id` 列と `name` 列を全リビジョンで突き合わせて集合差を取った。

途中のコミットで消して後から戻した、という履歴も無い（15本の CSV 変更コミットを 1本ずつ検査した）。

## 検査のやり直し方

```
git show <rev>:world/list/<file>.csv
```
を 2リビジョン分読み、`id` と `name` の集合差を取れば同じ結果になる。
CSV は BOM と改行コードがファイルごとに違うので、読み書きするときは必ず維持すること。
