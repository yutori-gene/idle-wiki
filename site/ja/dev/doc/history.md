### 引き継ぐ相手に伝えておくこと

- **決めたことの理由は plan.md に全部ある。** とくに Step 4 は元の公式表を3か所書き換えている（料理の秒数・読書の秒数・acq の公式）ので、数値をいじる前に「Step 4-3」「Step 4-5」の節を読む
- **`tier` は価格（`3^rare × tier`）と秒数の両方を動かす。** 4-4 で `earliest_period`（実測）に揃えたので、`tier` を動かすときは価格と秒数の再計算まで一式（plan.md「Step 4-4」節に不動点で回す手順）
- **check.py の22項目が 0件であることが、いまの CSV の唯一の保証。** 触ったら必ず回す
- **overview.md / overview.html は生成物。** 手で直しても次の生成で消える（`<!-- fill:X -->` ブロックだけは残る）
- **CSV に行を足すときは `id` と型列も一緒に書く。** `id` は英小文字ケバブケース・接頭辞なし・型内で一意（規則は plan.md「変換フェーズ 論点2」の「id 列」節）。`action.csv` の `req-N-type`／`acq-N-type` と `event.csv` の `acq-N-type` は現状すべて `item`。どちらも check.py が抜けを拾う
- **CSV の参照列は id ではなく name のまま。** `req-N-id` などに書くのは今も日本語の名前で、変換時に型ごとの name→id 辞書で解決する。だから name 重複検査は id を持たせた後も必要
