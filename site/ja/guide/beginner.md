# 初心者ガイド

はじめて遊ぶ人向けの道しるべ。数値やページの中身はワールドから自動で作っているが、このページは手書き。

## 最初の1時間

1. **公園で収集を回す。** 最初から開いているのは [<span class="wiki-icon">🌳</span>公園](/ja/category/park) だけ。まずは [<span class="wiki-icon">🍂</span>落ち葉拾い](/ja/action/gather-fallen-leaves) を実行する（タスク [<span class="wiki-icon">👣</span>はじめての一歩](/ja/event/first-step) が達成される）。連続のアクションは止めるまで繰り返し、オフライン中も進む
2. **公園のレベルを上げる。** アクションが成功すると、そのカテゴリに経験値が入ってレベルが上がる。レベルが上がるとアクションは速く・成功しやすくなり、必要Lvの高いアクションが開く
3. **拠点を開ける。** 公園 Lv4 で [<span class="wiki-icon">📦</span>倉庫](/ja/category/warehouse)、Lv6 で [<span class="wiki-icon">⚔️</span>近接武器](/ja/category/melee-weapon)、Lv8 で [<span class="wiki-icon">🌱</span>温室](/ja/category/greenhouse) が開く。開く条件は [進行チャート](/ja/reference/progression) にまとまっている
4. **武器を作って戦う。** 公園の討伐（スタミナ）は近接武器のカテゴリに経験値が入る。近接武器で合成した武器を装備すると戦闘が楽になる。勝てそうかどうかは各敵のページの「戦闘の見込み」を見る

## 気をつけること

- **物置（所持できるアイテムの種類数）は最初30種。** いっぱいになると新しい種類のアイテムを受け取れない。いらないものは売る。ダンジョンの探索で見つかる「容器」で一気に広がる（[<span class="wiki-icon">📦</span>物置](/ja/item/capacity)）
- **進行素材は売っても取り直せる。** 次のダンジョンを開くアイテム（[<span class="wiki-icon">⚽</span>伝説のボール](/ja/item/legendary-ball) など）は繰り返し入手できるアクションから出る
- **戦闘で力尽きると、実行中のアクションと作業予定がすべて止まる。** 放置する前に「1戦の被ダメ」が「回復」を上回っていないか確かめる
- **作業予定（キュー）は秘宝メダルで増やす。** [<span class="wiki-icon">📋</span>作業予定](/ja/item/queue) は [<span class="wiki-icon">🏅</span>秘宝メダル](/ja/item/treasure-medal) でしか買えない。秘宝メダルは秘宝グループのアイテムを手に入れると増える（[<span class="wiki-icon">🔍</span>秘宝の鑑定](/ja/event/treasure-appraisal)）
