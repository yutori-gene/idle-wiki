# 温室

<div class="wiki-infobox" style="--accent:#849b88"><div class="wiki-infobox-title">温室</div><div class="wiki-infobox-icon"><span class="wiki-icon-large">🌱</span></div><table><tr><th>グループ</th><td><a href="#/ja/group/base"><span class="wiki-icon">🏠</span>拠点</a></td></tr><tr><th>レベル</th><td>Lv1〜50</td></tr><tr><th>同時進行</th><td>他と並行して進む</td></tr><tr><th>アクション</th><td>18本</td></tr><tr><th>管理アイテム</th><td>31種</td></tr><tr><th>初期状態</th><td>ヒント表示</td></tr></table></div>

**生産型**の拠点（栽培）。種苗を植えて植物・食材を育てる。ほかのカテゴリと**並行して進む**（作業予定を使わない）ので、ダンジョンを回しながら放置できる。台所・地下室の材料の出どころ。

詳しいしくみは [装備とプロパティ](/ja/system/equipment)・[アクションの進み方](/ja/system/progress)。


## 解放条件

次をすべて満たすと解放される。

- [<span class="wiki-icon">🌳</span>公園](/ja/category/park) Lv8以上

**カテゴリの型**: 生産型

<details><summary>抜粋: plan.md › 生産型の雛形</summary>

「プロパティ経済」節で決めた供給内容（温室＝材料／台所＝生産系ブースト／地下室＝戦闘系ブースト）を、アクションの形に落とす。

###### 共通ルール

- **`progressType` は `persistent`。** 消耗品を繰り返し作れる必要がある（1-1 の `製作 → single` を訂正済み）
- **1出力＝1アクション。** 装備の「装備1種につきアクション1本」と同じ原則
- **道具は「装備」で表す。** `req` を `equipment=true, chance=0` にする（[fix.md](fix.md) B-1 の推奨形）

###### 道具を装備条件にするための `equipmentType` 変更

`impossible` と `unnecessary` は**装備できない**（[progress.ts:548](../../player/control/game/progress.ts#L548) が `necessary`/`consumable` 以外を `unequippable-item` で弾く）。装備条件にするなら型を変える必要がある。

| 道具 | 現在 | 変更 | `req` の形 |
|---|---|---|---|
| 調理器具（フライパン・鍋・ボウル） | `impossible` | **→ `necessary`** | `equipment=true, chance=0` |
| 調合器具（すり鉢・蒸留器・るつぼ） | `impossible` | **→ `necessary`** | `equipment=true, chance=0` |
| インフラ14種（オーブン等） | `unnecessary` | **変更しない** | `equipment=false, chance=0`（所持が条件） |

**インフラだけ例外にする。** `necessary` にすると効果が「装備枠の1つだけ」に落ち、「プロパティ経済」節で確定した**所持数比例の恒常バフが壊れる**。インフラは所持を条件にするだけで足りる。

`necessary` にした器具はカテゴリの装備枠に自動で載る（[progress.ts:286](../../player/control/game/progress.ts#L286) のとおり、`necessary`/`consumable` のグループは初期化時に `equipmentGroups` へ導かれる）。ただし**枠は `group` 単位で1つ**なので、`道具`／`器具` のままだと3種のうち1つしか装備できない。**器具は1種ごとに別グループへ分ける**（「旧系統の掃除」節）。

###### 温室（栽培）

**役割は「料理・ポーションの材料工場」**（案A）。ただし材料を温室産だけで閉じさせず、**ダンジョン由来の素材も混ぜる**。

| | |
|---|---|
| 本数 | 11 → ~~20本前後~~ **17本**（食材11＋薬草6。Step 3-2 で確定） |
| `req` | 種・苗 ×1、**`chance=0.8` 前後**（装備ではない。栽培のたびに確率で消費される） |
| `acq` | 食材 ×N（`chance`＝歩留まり）＋ **種・苗 ×1、`chance=0.3` 前後**（確率で同じ種が戻る） |
| 制約 | **消費 `chance` > 回収 `chance`。** 種は必ず目減りし、いずれ買い直し／拾い直しになる |

- 種・苗の入手は **購入（`buyingValue`）とダンジョン（収集）の両方**。温室の中だけでは完結させない
- `acq` での自己回収は入手経路タグに数えない（1-1 の注記）。種のタグは収集＋副タグ購入のまま
- ~~現状の「種＋作物自身を消費して作物を増やす」自己増殖ループは**廃止**する~~ ✅ Step 3-2 で廃止済み
- ~~栽培食材11種は本籍が街・北国・公園・台所・城・森に散っている~~ ✅ Step 3-2 で薬草6種ともども温室へ集約済み
