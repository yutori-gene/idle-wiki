詳しいしくみは [装備とプロパティ](/ja/system/equipment)・[アクションの進み方](/ja/system/progress)。


## 解放条件

次をすべて満たすと解放される。

- [<span class="wiki-icon">🌲</span>森](/ja/category/forest) Lv3以上

###### 容器9種は changed イベントで容量を配る（確定）

容量はワールドのアイテムでは増やせない（[fix.md](fix.md) B-9）。`events.changed` で「容器を入手した瞬間に capacity アイテムを +N」する形に置き換える。**エンジン改修は不要。**

| | |
|---|---|
| 本籍（`category`） | **庭のまま**（1-2 の「`category`＝管理場所」規約） |
| 入手経路タグ | **探索**。棺桶が既に地獄から出ているのに合わせ、各ダンジョンの `single` 報酬として1個ずつ配る |
| `equipmentType` | `unnecessary` のまま。`p-*` も全ゼロのまま（効果は changed 経由） |
| `maximum` | **全種 1 に統一**（現状9種中6種が無制限） |
| changed イベント | 容器1種につき1本、計9本。`req=<容器> x1` → `acq=<capacity アイテム> xN` |

**入手は必ず単発にする。** changed は「1回の増加量」で判定するため、重複入手のたびに再発火して容量が青天井になる。`maximum=1` では止まらない（[fix.md](fix.md) B-9 の前提2）。rare 0〜8 に散る9種を10ダンジョンへほぼ1対1で割り当てれば、単発性が自然に確保できる。

**9本を書いた（2026-09-11）。** `event.csv` の末尾に `storage-*` として9行。`req=<容器>×1` → `acq=物置×N`、`timing=changed`・`category=庭`・`group` 空欄。

| 容器 | ダンジョン | 物置 +N |
|---|---|--:|
| エコバッグ | 公園 | 10 |
| 壺 | 森 | 10 |
| リュックサック | 街 | 15 |
| カンガルーの袋 | 海 | 15 |
| ホイポイカプセル | 北国 | 20 |
| 観覧車のゴンドラ | 工場 | 20 |
| 棺桶 | 火山 | 25 |
| 3次元ポケット | 地獄 | 30 |
| エントリープラグ | 天空のお庭 | 35 |

- **厚みの根拠は「枠を永久に占めるアイテム126種」。** 売却も消費もできないもの＝秘宝29・ペット19・知識15・インフラ14・能力10・特別品9・容器9・美術品14・器具7。初期30＋容器180＝**210** なら、126 を抱えたうえで素材と装備に84枠残る。容量購入（100×1.5^(n-1)）は10枠で累計11,340コイン・15枠で87,200コインなので、現実に買えるのは10〜15枠。**容器が容量の主役で、購入は序盤の補助**という配分になる

- **実エンジンで確認した**（player のコードを Node で駆動）: 30 →（9種そろえて）**210**。`getMaxCapacity()` は capacity アイテムの `countNow` をそのまま返すので、changed の `acq` がそのまま容量になる

**バッチ2 の7本目＝拠点の最後。** [plan.md](../doc/plan.md)「委任型の雛形」がやることを列挙してあったので、それを順に当てただけ。**35 → 22本**（ペット19＋討伐3）。

### ペット19種＝アクション19本の1対1

`九尾の狐` 5本・`R2D2` 2本・`五毛猫` 2本という偏りを均した。`progressType` は **`persistent` に統一**（現状 persistent 13・single 7・snap 5 が混在していて、1-1 のタグ11「委任＝persistent」に反していた）。

**ペット本体の `req` を全件 `chance=0`（所持が条件）にした。** それまでは `chance=1` で**1回でペットが消滅する**形で、`snap` 5本（`メダカを観察する`・`ペンペンをなだめる`・`オウム返しするオウムと話す`・`五毛猫に頼みごとをする`・`九尾の狐を撫でる`）だけが `acq` に同じペットを置いて自己回収する回避策になっていた。所持条件にすれば回避策ごと要らない。

`maximum` はペット19種・容器9種とも全件 **1**。`unnecessary` は所持数比例で効くので、上限が無いと補正が青天井になる（容器は容量が青天井になる）。

**`category.csv` の `庭` を `standaloneProgress=O` にした。** 1-2 のカテゴリ型で委任型は standalone ○ と決めたのに空だった。これで温室・書斎と並んで裏で回る。

### 産物は素材・食材に揃えた

**装備と美術品をペットの `acq` から外した。** `秘石`（装飾 tier4）を `ケロちゃん`・`R2D2`・`九尾の狐` が、`ハートのカケラ`・`熱い想い`（寝室/美術品）を `ジョーンズ`・`五毛猫`・`炎のキツネ` が落としていたが、どちらも**二重経路**。装飾は拾う装備として海で、美術品は寝室で作るのが本籍。

代わりに **ペットが「働いて持ち帰るもの」**に寄せた。`ペンペン`＝魚、`負け犬`＝骨、`ハムスター`＝小麦（回し車で臼を回す）、`オウム`＝街の噂を仕入れてコイン、`ジョーンズ`＝海賊の地図、`炎のキツネ`＝狐火と炭、`R2D2`＝歯車とワイヤー。

**`庭/素材` の `魚` に初めて出所が付いた**（`ペンペンに魚を獲らせる`・`ケロちゃんを水浴びさせる`）。

### 討伐3本は害虫駆除として残した

`ニワトリ`・`パンシー`・`ミミズ`。委任型に `stamina` が混ざるが、庭で害虫を駆除する筋は通る（雛形で確定済み）。**`庭/ミミズ` の `acq` にあった参照切れ `スライム改造版` を外して、参照切れが 4 → 3 になった。**

### 旧系統の分解7本を廃止／`庭/道具` を倉庫へ寄せた

`ツルハシ`・`クワ`・`シャベル`・`ハサミ`・`ペイントローラー`・`斧`・`サーフボード` を分解して鉄と枝に戻す7本。旧系統（`〜の分解` の `persistent`）なので廃止した。

`庭/道具` 5種は**本籍を `倉庫/道具` へ移した**。決定5 の割り振り表どおりで、**ダンジョンの `acq` に置けるのは倉庫のグループだけ**なので、庭に置いたままでは配れない。
