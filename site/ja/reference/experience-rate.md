# 経験値効率表

カテゴリごとに、経験値が入るアクションの「1時間あたりの経験値」をレベル差別に並べる（装備なし）。系統を持つアクションは、配分のうちそのカテゴリへ入るぶん。レベル差が大きいほど速く・成功しやすくなるが1回の経験値は減るので、効率の良いアクションはレベルとともに移る。
