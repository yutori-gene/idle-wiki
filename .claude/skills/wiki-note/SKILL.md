# 手書きの追記・手書きページ

正本は [RULES.md](../../../RULES.md) の「手書きの追記（notes）」。

## どこに書くか

| 書きたいもの | ファイル |
|---|---|
| 要素ページ（カテゴリ・アクション・アイテム・スキル・イベント・グループ）への説明 | `notes/ja/<種別>/<id>.md` |
| 一覧・参照表・トップ・開発者ページへの説明 | `notes/ja/<そのページのパス>.md`（例: `notes/ja/list/items.md`・`notes/ja/README.md`） |
| 新しい手書きページ | `notes/ja/pages/<パス>.md`。サイドバーに出すなら `config/wiki.ts` の `sidebarPages` に足す |

追記はページの説明文の直後（データの表より前）に差し込まれる。

## 書き方

- 要素へのリンクは `[[item:lemon]]`・`[[category:park|公園]]`。**名前ではなく id**（ページの「開発者向け情報」か `source/world/world.json` で調べる）
- **数値は書かない。** 「〇〇の表を見る」と誘導する
- 注意書きは `?> ` で始まる段落
- ゲームの用語はゲーム内の呼び方（連続／単発／即時／スタミナ、攻撃／防御／精度／回避／回復 など）
- ワールドのデータから言えないこと（設計意図・攻略の勘所）を書く。データを言い換えるだけの文は書かない

## 書いたら

`npm run wiki-generate && npm run wiki-check` を通し、`npm run wiki-serve` で表示を確かめる。
